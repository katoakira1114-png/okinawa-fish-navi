# 沖縄魚市場 出荷・相場ナビ (Okinawa Fish Market Navi)

八重山（石垣島）および沖縄本島（JF泊・那覇地区）の魚市場セリ相場予測＆手取り比較シミュレーターです。

## 特徴
- **誰でもアクセス可能**: ログイン不要、複数GoogleアカウントのChromeでも快適に閲覧・利用できます。
- **スマホ最適化 PWA**: Chromeで「ホーム画面に追加」すると単独アプリとして起動します。
- **八重山拠点 vs 那覇出荷の手取り比較**: 航空便・船便の送料、梱包費、輸送日数を反映した実質手取りを自動計算。
- **生け保管対応**: イセエビ類などは最大14日先までの日別相場予測と手取り差額を比較。
- **完全ブラウザ内計算**: 機密設定や入力した魚種・数量は外部サーバーに送信されず、手元のブラウザ内で安全に計算・保存（localStorage）されます。
